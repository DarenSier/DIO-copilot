# DIO-copilot
Resumo sobre criação de COPILOT

A criação de um Copilot pode partir de diferentes abordagens, dependendo do nível de personalização desejado:
•	Baseado em modelo: utiliza um modelo ou estrutura previamente configurada como ponto de partida. É uma opção mais rápida, pois grande parte da configuração inicial já está definida, permitindo personalizar o Copilot conforme a necessidade. 
•	Por descrição de IA: o usuário descreve, em linguagem natural, o que deseja que o Copilot faça, para quem ele será utilizado e quais tarefas deverá executar. A inteligência artificial utiliza essa descrição para criar uma estrutura inicial, que posteriormente pode ser ajustada. 
•	Em branco: inicia o Copilot sem uma configuração prévia. Permite definir manualmente suas características, instruções, conhecimentos, comportamentos, ações e demais componentes. É a opção que oferece maior liberdade de configuração, mas exige mais trabalho inicial.
